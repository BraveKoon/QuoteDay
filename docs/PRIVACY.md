# QuoteDay 개인정보 처리방침

**시행일: 2026년 9월 14일**

## 한 줄로

QuoteDay 는 **계정을 만들지 않습니다.** 이름도, 이메일도, 전화번호도 받지 않습니다.
일정·노트·기록은 **이 기기 안에만** 있고, 하트와 챌린지 순위만 애플의 iCloud 를 거칩니다.
광고도 없고, 추적도 하지 않으며, 분석 도구를 넣지 않았습니다.

---

## 1. 기기 안에만 남는 것

아래는 **기기를 떠나지 않습니다.** 앱을 지우면 함께 사라집니다.

| 무엇 | 어디에 |
|---|---|
| 일정 (제목·시간·메모·반복) | 기기 안 데이터베이스 |
| 명언 노트 | 기기 안 데이터베이스 |
| 챌린지 기록 (최고 점수·푼 판 수) | 기기 설정 저장소 |
| 앱 설정 (알림 시각, 화면 모드, 선호 분류) | 기기 설정 저장소 |
| 만든 명언 카드 | 저장을 누른 경우에만 사진 앱 |

이 값들은 홈 화면 위젯이 같은 내용을 보여 줄 수 있도록 앱과 위젯이 공유하는
저장 공간(App Group)에 둡니다. 그래도 기기 밖으로는 나가지 않습니다.

## 2. 애플 iCloud 로 가는 것

**하트**와 **챌린지 순위**는 여러 사람이 함께 보는 기능이라 애플의
CloudKit 공개 데이터베이스를 씁니다. 저장되는 것은 이것뿐입니다.

- **하트** — 어느 명언에 하트를 눌렀는지, 그리고 명언마다의 전체 하트 수
- **챌린지 순위** — 이번 시즌 총점과 점수 구간별 인원수

여기에는 애플이 앱마다 다르게 만들어 주는 **익명 사용자 식별자**가 함께 붙습니다.
같은 사람이 같은 명언에 하트를 두 번 세지 않게 하고, 다른 기기에서도 내 하트를
그대로 보여 주기 위해서입니다. 이 식별자로는 **누구인지 알 수 없고**,
개발자는 여러분의 iCloud 계정이나 이메일을 볼 수 없습니다.

**다른 사람에게 보이지 않는 것:** 이름, 닉네임, 점수, 몇 등인지. 순위 화면은
"내가 전체에서 어디쯤인지"만 알려 주고 다른 사람의 정보는 보여 주지 않습니다.

이 데이터는 애플의 서버에 저장되며 개발자는 별도의 서버를 두지 않습니다.
애플의 처리 방침은 [Apple 개인정보 보호정책](https://www.apple.com/legal/privacy/kr/)을 따릅니다.

iCloud 에 로그인하지 않아도 앱은 그대로 동작합니다. 하트는 이 기기에만 남습니다.

## 3. 외부로 나가는 요청

**[ZenQuotes](https://zenquotes.io/)** — "오늘의 명언"을 하루 한 번 받아 옵니다
(설정에서 끌 수 있습니다). 이때 **보내는 사용자 정보는 없습니다.** 인터넷 통신의
성질상 접속하는 쪽의 IP 주소는 상대 서버에 남습니다.

영어 명언의 한국어 번역은 **기기 안에서** 처리합니다(애플 Translation 프레임워크).
문장이 번역을 위해 밖으로 나가지 않습니다.

그 밖의 외부 통신은 없습니다. 광고 네트워크, 분석 도구, 제3자 SDK를 넣지 않았습니다.

## 4. 기기 권한

모두 **선택**입니다. 허용하지 않아도 앱의 나머지는 그대로 씁니다.

- **알림** — 정해 둔 시각에 명언을, 일정 시각에 알림을 띄우기 위해. 알림은 모두
  기기가 직접 띄우며 서버를 거치지 않습니다.
- **캘린더** — 기기 일정을 함께 보여 주고, 앱에서 만든 일정을 기기 캘린더에 넣기 위해.
  읽은 일정을 어디로도 보내지 않습니다.
- **사진 추가** — 만든 명언 카드를 저장하기 위해. **기존 사진을 읽지 않습니다.**

## 5. 하지 않는 것

- 광고 식별자(IDFA)를 쓰지 않고, 앱 추적 권한을 요청하지 않습니다.
- 다른 회사의 데이터와 맞춰 보지 않습니다.
- 어떤 데이터도 팔거나 광고에 쓰지 않습니다.
- 사용 기록을 분석 서비스로 보내지 않습니다.

## 6. 만 14세 미만

특정 연령을 겨냥해 만든 앱이 아니며, 나이를 묻지도 수집하지도 않습니다.
계정이 없으므로 개인을 식별할 수 있는 정보가 모이지 않습니다.

## 7. 보관과 삭제

- **기기 안의 것** — 앱을 지우면 함께 사라집니다.
- **하트** — 하트를 다시 눌러 해제하면 서버에서도 지워집니다.
- **챌린지 점수** — 랭킹은 석 달마다(1·4·7·10월 1일) 새 시즌으로 넘어가고, 지난 시즌
  기록은 더 이상 쓰이지 않습니다. 지금은 앱 안에서 점수 기록을 직접 지우는 방법이
  없습니다. 지우기를 원하시면 아래 연락처로 알려 주세요.
